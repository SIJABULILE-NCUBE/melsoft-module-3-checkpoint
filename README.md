## About This Project

This project is my Module 3 checkpoint for JavaScript Essentials 1.It focuses on JavaScript operators,expressions,and user interaction through practical and interview-style challenges.

## Topics Covered

- Arithmetic,assignment,comparison,and logical operators
- Unary and ternary operators
- Equality and operator precedence
- Short-circuit evaluation
- Optional chaining and nullish coalescing
- `typeof`,`instanceof`,and `delete`
- Bitwise operators and permissions
- Banking calculations
- User interaction
- Debugging and bug fixing

## Project Files

### `sijabulile-ncube-module3.js`

Contains Challenges 1 to 7,9,and 10.

### `challenge8.html`

Contains Challenge 8,which uses `alert()`,`prompt()`,and `confirm()` for browser-based user interaction.

## Running The Project

Run the main JavaScript file using:

```bash
node sijabulile-ncube-module3.js
```

Open `challenge8.html` in a browser to run Challenge 8.

## What I Learned

This project helped me understand how JavaScript operators work in practical situations.I also learned how small differences between operators can affect the result of my code,and why it is important to understand what JavaScript is doing instead of only focusing on the final output.
